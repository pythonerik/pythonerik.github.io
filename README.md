# Personal Website

This repository contains the source for Erik Aranda-Wikman's personal website. The site is a resume-driven experience that includes:

- A home page that introduces Erik's focus on insurance education.
- An about page highlighting guiding principles and hobbies.
- A resume page outlining professional experience and education.
- A projects page featuring the "Insurance Education Content" initiative.
- A contact page with ways to collaborate.

All pages share a cohesive design system implemented in `assets/style.css` and interactivity for the responsive navigation in `assets/main.js`.
